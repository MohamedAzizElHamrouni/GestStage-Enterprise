# GestStage-Enterprise
GestStage est une application console Java N-Tiers (DAO/Services) conçue pour la gestion complète des stages académiques. Elle interconnecte étudiants, entreprises, encadrants et administrateurs. Fonctionnalités clés : publication d'offres, suivi des candidatures, journalisation des accès, sécurité (hachage) et export de rapports au format PDF
